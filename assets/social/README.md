# Social preview images

1280×640, one per repository that is pinned or linked from a launch post.
GitHub shows this image whenever a repository link is shared on X,
LinkedIn, Slack or Discord; without one, it shows a generic card.

GitHub has no API for this setting, so each one is uploaded by hand:
**repository → Settings → General → Social preview → Edit → Upload an image**.
